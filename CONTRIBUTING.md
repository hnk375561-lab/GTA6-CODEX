# Contributing to Sin Frenos

Thanks for your interest in improving this project! This document explains how to add or edit content, and what's expected before opening a Pull Request.

> actual) — ver la FAQ en README.md para el detalle. El producto se
> llama Sin Frenos; este archivo se corrigió el 12/09/2026 para dejar de
> ser el único lugar del repo que todavía decía "GTA6-CODEX" sin
