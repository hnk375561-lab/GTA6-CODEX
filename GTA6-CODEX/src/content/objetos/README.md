# Objetos de GTA 6

Catálogo de objetos interactuables y items del mundo de Grand Theft Auto VI.

## Estructura

Cada objeto se documenta con:

- **Slug**: Identificador URL-safe único
- **Título**: Nombre del objeto
- **Descripción**: Resumen de una línea
- **Contenido**: Descripción detallada
- **Estado**: `confirmado` | `rumor` | `nuestro`
- **Categoría**: Tipo de objeto
- **Interacción**: Cómo el jugador interactúa
- **Relaciones**: Ubicaciones, misiones, personajes

## Categorías de Objetos

### Por Tipo
- **Herramientas**: Items de utilidad
- **Consumibles**: Comida, bebidas, drogas
- **Dinero/Recursos**: Efectivo, monedas, recursos
- **Artículos**: Documentos, fotos, información
- **Coleccionables**: Objetos para coleccionar
- **Interactuables**: Objetos que se pueden usar

### Por Función
- **Heal/Buff**: Recuperan salud o dan bonificaciones
- **Economía**: Generan dinero o son valiosos
- **Narrativa**: Importantes para la historia
- **Exploración**: Descubribles en el mundo

## Naming Conventions

- Slugs en `kebab-case`
- Títulos descriptivos
- Evitar jerga innecesaria
- Usar nombres oficiales si están confirmados

## Enlaces Relacionados

Los objetos se conectan a:
- **Ubicaciones** donde se encuentran
- **Personajes** que los usan
- **Misiones** que los requieren
- **Actividades** relacionadas
- **Vehículos** que pueden contenerlos
