# GTA6-CODEX 📚

Una enciclopedia completa de **Grand Theft Auto VI** con contenido multimedia, bases de datos y análisis.

## 📁 Estructura del Repositorio

\\\
GTA6-CODEX/
├── incoming-images/        # Imágenes descargadas y clasificadas
│   ├── personajes/          # Protagonistas y personajes secundarios
│   ├── ubicaciones/         # Mapa, distritos y localidades
│   ├── vehiculos/           # Vehículos confirmados
│   ├── heroes/              # Artwork y promocionales
│   └── INDEX.md             # Inventario completo
├── assets/                  # Assets optimizados
│   ├── artworks/            # Oficiales y promocionales
│   ├── characters/          # Personajes organizados
│   ├── locations/           # Ubicaciones del mapa
│   └── vehicles/            # Base de datos de vehículos
├── scripts/
│   └── process-images.mjs   # Script de procesamiento automático
└── README.md                # Este archivo
\\\
